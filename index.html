Reglas de seguridad

Las señales se calculan con entrenamiento y evaluación separados temporalmente (60% / 40%). La comparación es retrospectiva y no garantiza un rendimiento futuro.

Las operaciones requieren un precio importado o descargado, su moneda y, si corresponde, el tipo de cambio USD/CLP. El costo incluye comisión y spread estimado, pero no impuestos.

Cuando la API no responde, el motor muestra un error y no fabrica precios. No se permite comprar con cotizaciones de más de dos días de antigüedad. Los CSV pueden contener datos antiguos; se verifica su fecha.
