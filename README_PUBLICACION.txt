BOLSAIA WEB - PUBLICACIÓN GITHUB PAGES

1. Crea una cuenta en github.com si no tienes.
2. Crea un repositorio público, por ejemplo bolsaia-web.
3. En Add file > Upload files, sube los archivos de esta carpeta (NO el ZIP). Confirma los cambios.
4. En Settings > Pages > Build and deployment, selecciona Deploy from a branch, rama main y carpeta /(root). Guarda.
5. Espera el despliegue y abre la URL indicada por GitHub Pages (normalmente https://USUARIO.github.io/bolsaia-web/).
6. En Chrome Android, menú ⋮ > Añadir a pantalla principal > Instalar (si aparece).

IMPORTANTE: el alojamiento HTTPS no garantiza acceso a APIs de terceros (CORS, limites, disponibilidad). No subas contraseñas, tokens ni datos privados a un repositorio público. Esta app no opera dinero real. Los datos guardados al abrir desde content:// NO se trasladan automáticamente al nuevo dominio; exporta CSV como respaldo.
